## 9. US-D1 Customizations

The US-D1 Radar Altimeter has several hardware and firmware customization options. All customizations can be requested by contacting Ainstein directly but may be subject to volume requirements.

The following US-D1 hardware customizations can be requested prior to purchasing.

- US-D1 PCB (no enclosure)
- Interface Protocol (CAN, UART, DroneCAN)
- Modified connector (JST, bare wire)
- Extended Cable (1 meter).
- BAUD Rate (38400, 57600, 115200, 250 Kbps, 500 Kbps, 1Mbps)
- DroneCAN Node ID (1~127)
