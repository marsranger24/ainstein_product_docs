## Ainstein FW Release Notice

The previously public release version was: 24 GHz PL FW V98.255.0.3, 24 GHz PS FW  
V98.252.2.2, and 60 GHz APP FW V97.251.1.0

The new public release version is: **24 GHz PL FW V98.255.0.5, 24 GHz PS FW V98.251.2.3,  
60 GHz APP FWV97.251.1.0**

Updates and upgrades to the LR-D1 Pro through the new Firmware include:

- Upgrade in the LR-D1 Pro CAN recovery

Please reach out to the Ainstein team via [support@ainstein.ai](mailto:support@ainstein.ai) with any inquiries about this or  
previous FW versions.
