## Ainstein US-D1 Firmware Release Notice

The previously public release version was: v1.8.3

The new public release version is: **v2.4.0**  
Updates and upgrades to the US-D1 through the new Firmware include:

- Improved CAN bus recovery
- DroneCAN compatibility

Please reach out to the Ainstein team via [support@ainstein.ai](mailto:support@ainstein.ai) with any inquiries about this or  
previous FW versions.

The following table is the Firmware Change Log of the US-D1 (also  
available in the Technical User Manual).

<br />

| Firmware Version | Update Features                                                                        | Firmware Release Date |
| ---------------- | -------------------------------------------------------------------------------------- | --------------------- |
| v1.5.3           | Added support for the new MCU model                                                    | 11/20/20201           |
| v1.5.3N          | 1. Optimize FM bandwidth to comply with FCC certification 2. Fix for minor offset bugs | 03/13/2021            |
