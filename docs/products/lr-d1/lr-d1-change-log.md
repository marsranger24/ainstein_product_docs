## Ainstein LR-D1 Firmware Release Notice

The Ainstein team presents the following Notice to let the LR-D1 user know of the new release  
of a firmware version for the Radar Altimeter.  
The previously public release version was: v18.0.1.3  
The new public release version is: v19.0.0.1  
Updates and upgrades to the LR-D1 through the new Firmware include:  
● Introducing Out-of-Range logic and a new data format  
● Updated compatibility with ArduPilot  
Please reach out to the Ainstein team via [support@ainstein.ai](mailto:support@ainstein.ai) with any inquiries about this or  
previous FW versions.  
Attached to the second page of this Notice is the Firmware Change Log of the LR-D1 (also  
available in the Technical User Manual).
